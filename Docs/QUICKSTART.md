# FS-Code Quick Start Guide

**Get started with FS-Code in 30 seconds!**

---

## 🚀 Fastest Way to Run

```bash
# Just run this command:
python3 app.py
```

That's it! The IDE will open immediately.

---

## 🎯 First Steps

1. **Write some Python code** in the editor
2. **Press F5** to run your code
3. **See the output** at the bottom

### Example Code to Try

```python
# Type this in the editor and press F5:
print("Hello, FS-Code!")

for i in range(5):
    print(f"Number {i}")

result = sum([1, 2, 3, 4, 5])
print(f"Sum: {result}")
```

---

## ⌨️ Essential Keyboard Shortcuts

- **F5** - Run your code
- **Ctrl+S** - Save file
- **Ctrl+N** - New file (new tab)
- **Ctrl+O** - Open file

---

## 🎨 What You'll See

- **Modern Dark Theme** - Easy on the eyes
- **Syntax Highlighting** - Keywords, strings, and comments in color
- **Line Numbers** - On the left side
- **Output Console** - At the bottom (green = success, red = errors)
- **Status Bar** - At the very bottom (blue)

---

## 💡 Tips

1. **Multiple Files**: Press Ctrl+N to open a new tab
2. **Unsaved Changes**: See the asterisk (*) in the tab name
3. **Clear Output**: Click the "🗑️ Clear" button
4. **Close Tab**: Press Ctrl+W
